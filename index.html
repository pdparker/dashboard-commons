Phil's Dashboard Suite · Shared Infrastructure

Dashboard Commons

Single source of truth for the six-dashboard suite: the institution registry, ACU design tokens, the suite nav strip, URL-state helpers, and the freshness-manifest schema the hub reads.

1 · Suite nav strip (rendered live above when integrated)

Each dashboard adds one line — the strip injects itself at the top of the page:

<script src="https://pdparker.github.io/dashboard-commons/commons.js"
        data-dash="edu-numbers" defer></script>

Valid data-dash ids: cricos, edu-numbers, outcomes, staff, rankings, student-signals. Omit the attribute to load the API without any UI.

2 · Institution registry

institutions.json — canonical names, every alias used across the suite's data sources, state, and peer-group membership (Go8 · ATN · IRU · RUN · SACRU). Live check: loading…

const reg = await DashCommons.registry();
reg.lookup("Royal Melbourne Institute of Technology").id  // "rmit-university"
reg.inGroup("go8")                                        // 9 institutions
reg.byId["australian-catholic-university"].groups         // ["sacru"]

3 · URL state — shareable filters

DashCommons.state.set('inst', 'australian-catholic-university');
DashCommons.state.get('inst');          // read back (survives reload/share)
DashCommons.state.set('inst', null);    // remove

5 · Freshness manifest

Each dashboard publishes manifest.json at its root (schema · example). The hub fetches these to show last-updated and data-vintage badges per card — staleness at a glance.
